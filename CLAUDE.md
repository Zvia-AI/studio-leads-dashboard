# Studio Leads Dashboard - course project

This folder is a small static dashboard built for an AI course assignment.
It is a separate project from any other project on this computer.

## Read first
- Before every step, read `SPEC.md` (what to build) and `PRACTICE.md` (how to work).
- If the work changes the data structure or design, update `SPEC.md` in the same step.

## Scope and safety (highest priority)
- Work only inside this folder. Never read, edit or run anything outside it.
- Never run `git config --global`, never change global git settings or credentials.
- This repository is PUBLIC. Never put keys, tokens, passwords or real personal details in any file. All data in `data.js` must be fake.
- Do not install packages or tools without asking first. The project is plain HTML, CSS and JavaScript, with libraries loaded from a CDN.

## Working style
- One build phase at a time, following section 6 of `SPEC.md`.
- Branches: phase 1 on main, phases 2-6 each in their own branch. See PRACTICE.md section 3.
- After each phase: show what changed, stop, and wait for Zvia to review it in the browser.
- Commit and push only after Zvia says the phase is approved. Commit messages follow `PRACTICE.md`.
- Ask for permission before each action. Never suggest "allow all".
- Before any `git push`, run `git status` and `git log --oneline -3` and show the output.
- Never run destructive git commands (`reset --hard`, `push --force`, `clean -f`, branch deletion) without asking first.

## Language
- UI text is Hebrew, RTL, written in gender-neutral phrasing (action names, not imperatives).
- In Hebrew text use a hyphen (-), never an em-dash.
- Explain things to Zvia in Hebrew. Code, file names and commands stay in English.
