# דאשבורד לידים - סטודיו שקד

דאשבורד שמציג תמונת מצב עדכנית של הלידים (פניות לקוחות) של הסטודיו - כמה פניות פעילות יש, מה שוויין, כמה פגישות ייעוץ מתוכננות החודש, ואיזה אחוז מהפניות הסתיים בעבודה בפועל. הדאשבורד מיועד לבעלי הסטודיו, לשימוש יומיומי מהנייד או מהמחשב, בלי צורך בהתקנה.

## מדריך שימוש קצר

**כרטיסי המדדים וגרף המשפך:**
בחלק העליון של הדף מוצגים ארבעה כרטיסים: מספר הלידים הפעילים (לא כולל לידים שנסגרו בהצלחה או שאינם רלוונטיים), השווי הכספי המשוער של הלידים הפעילים, מספר פגישות הייעוץ המתוכננות בחודש הנוכחי, ואחוז הסגירה (לידים שנסגרו בהצלחה מתוך כל הלידים הרלוונטיים). גרף "משפך מכירות" מציג כמה לידים נמצאים בכל שלב, מהפנייה הראשונה ועד הסגירה. גרף "התפלגות שירותים" מציג את חלוקת כל הלידים לפי סוג השירות המבוקש.

**חיפוש, סינון ומיון בטבלה:**
בטבלת הלידים אפשר לחפש לפי שם או טלפון בתיבת החיפוש, ולסנן בנפרד לפי שלב ולפי סוג שירות (בחירת "הכול" מבטלת את הסינון). החיפוש והסינון פועלים יחד. לחיצה על הכותרת "שווי משוער" או "תאריך פנייה" ממיינת את הטבלה לפי העמודה הזו, ולחיצה חוזרת הופכת את כיוון המיון.

**הוספת ליד ושמירת נתונים:**
לחיצה על "הוספת ליד" פותחת חלונית למילוי פרטי הליד (שם, טלפון, סוג שירות וסוג נכס הם שדות חובה). אחרי השמירה הליד מופיע מיד בטבלה, במדדים ובגרפים, ונשאר גם אחרי רענון הדף או סגירת הדפדפן. כפתור "איפוס נתוני הדגמה" מוחק את כל הלידים שנוספו ומחזיר את הדאשבורד לנתוני ההדגמה המקוריים, אחרי אישור.
