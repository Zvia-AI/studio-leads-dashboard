# דאשבורד לידים - סטודיו שקד

דאשבורד שמציג תמונת מצב עדכנית של הלידים (פניות לקוחות) של הסטודיו - כמה פניות פעילות יש, מה שוויין, כמה פגישות ייעוץ מתוכננות החודש, ואיזה אחוז מהפניות הסתיים בעבודה בפועל. הדאשבורד מיועד לבעלי הסטודיו, לשימוש יומיומי מהנייד או מהמחשב, בלי צורך בהתקנה.

## מדריך שימוש קצר

**כרטיסי המדדים וגרף המשפך:**
בחלק העליון של הדף מוצגים ארבעה כרטיסים: מספר הלידים הפעילים (לא כולל לידים שנסגרו בהצלחה או שאינם רלוונטיים), שווי הפרויקטים בתהליך (סכום השווי המשוער של הלידים הפעילים), מספר פגישות הייעוץ המתוכננות בחודש הנוכחי, ואחוז הסגירה (לידים שנסגרו בהצלחה מתוך כל הלידים הרלוונטיים). גרף "משפך מכירות" מציג כמה לידים נמצאים בכל שלב, מהפנייה הראשונה ועד הסגירה. גרף "התפלגות שירותים" מציג את חלוקת כל הלידים לפי סוג השירות המבוקש.

**חיפוש, סינון ומיון בטבלה:**
בטבלת הלידים אפשר לחפש לפי שם או טלפון בתיבת החיפוש (חיפוש הטלפון מתעלם ממקפים ורווחים), ולסנן בנפרד לפי שלב ולפי סוג שירות (בחירת "הכול" מבטלת את הסינון). החיפוש והסינון פועלים יחד. לחיצה על הכותרת "שווי משוער" או "תאריך פנייה" ממיינת את הטבלה לפי העמודה הזו, ולחיצה חוזרת הופכת את כיוון המיון. ליד בלי שווי משוער מוצג עם "-" בעמודה הזו.

**הוספת ליד ושמירת נתונים:**
לחיצה על "הוספת ליד" פותחת חלונית למילוי פרטי הליד (שם, טלפון, סוג שירות וסוג נכס הם שדות חובה). מספר טלפון מתוקן אוטומטית לתבנית ישראלית רגילה (לדוגמה 050-123-4567); מספר לא תקין מציג הודעת שגיאה. אחרי השמירה הליד מופיע מיד בטבלה, במדדים ובגרפים, ונשאר גם אחרי רענון הדף או סגירת הדפדפן. כפתור "איפוס נתוני הדגמה" מוחק את כל הלידים שנוספו ומחזיר את הדאשבורד לנתוני ההדגמה המקוריים, אחרי אישור.

**עריכה ומחיקה של ליד:**
בעמודת "פעולות" שבטבלה, לידים שנוספו דרך הדאשבורד מציגים שני כפתורים - "עריכה" ו"מחיקה". עריכה פותחת את אותה חלונית מלאה מראש בפרטי הליד, עם אפשרות לשנות גם את השלב. מחיקה מבקשת אישור לפני שהליד נמחק לצמיתות. לידי ההדגמה המקוריים קבועים ואינם ניתנים לעריכה או מחיקה (עמודת הפעולות ריקה בשבילם).
