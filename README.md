# דאשבורד לידים - סטודיו שקד

דאשבורד שמציג תמונת מצב עדכנית של הלידים (פניות לקוחות) של הסטודיו - כמה פניות פעילות יש, מה שוויין, כמה פגישות ייעוץ מתוכננות החודש, ואיזה אחוז מהפניות הסתיים בעבודה בפועל. הדאשבורד מיועד לבעלי הסטודיו, לשימוש יומיומי מהנייד או מהמחשב, בלי צורך בהתקנה.

## קישור לאתר החי
יתווסף בפרסום

## מדריך שימוש קצר
הדאשבורד עדיין בבנייה. המדריך המלא, עם כל הפרטים הבאים, יושלם בשלב הבנייה האחרון (ליטוש ופרסום):
* איך מסננים ומחפשים לפי סוג שירות ושלב: בטבלת הלידים אפשר לחפש לפי שם או טלפון בתיבת החיפוש, ולסנן בנפרד לפי שלב ולפי סוג שירות (בחירת "הכול" מבטלת את הסינון). החיפוש והסינון פועלים יחד.
* איך קוראים את כרטיסי המדדים ואת גרף המשפך.
* איך מוסיפים ליד חדש, ומה קורה לנתונים אחרי רענון הדף: לחיצה על "הוספת ליד" פותחת חלונית למילוי פרטי הליד. אחרי השמירה הליד מופיע בטבלה, במדדים ובגרפים, ונשאר גם אחרי רענון הדף. כפתור "איפוס נתוני הדגמה" מוחק את כל הלידים שנוספו ומחזיר את המצב המקורי, אחרי אישור.
