# דאשבורד לידים - סטודיו שקד

דאשבורד שמציג תמונת מצב עדכנית של הלידים (פניות לקוחות) של הסטודיו - כמה פניות פעילות יש, מה שוויין, כמה פגישות ייעוץ מתוכננות החודש, ואיזה אחוז מהפניות הסתיים בעבודה בפועל. הדאשבורד מיועד לבעלי הסטודיו, לשימוש יומיומי מהנייד או מהמחשב, בלי צורך בהתקנה.

## קישור לאתר החי
https://zvia-ai.github.io/studio-leads-dashboard/

## מדריך שימוש קצר

**כרטיסי המדדים וגרף המשפך:**
בחלק העליון של הדף מוצגים ארבעה כרטיסים: מספר הלידים הפעילים (לא כולל לידים שנסגרו בהצלחה או שאינם רלוונטיים), שווי הפרויקטים בתהליך (סכום השווי המשוער של הלידים הפעילים), מספר פגישות הייעוץ המתוכננות בחודש הנוכחי, ואחוז הסגירה (לידים שנסגרו בהצלחה מתוך כל הלידים הרלוונטיים). גרף "משפך מכירות" מציג כמה לידים נמצאים בכל שלב, מהפנייה הראשונה ועד הסגירה. גרף "התפלגות שירותים" מציג את חלוקת כל הלידים לפי סוג השירות המבוקש.

**חיפוש, סינון ומיון בטבלה:**
בטבלת הלידים אפשר לחפש לפי שם או טלפון בתיבת החיפוש (חיפוש הטלפון מתעלם ממקפים ורווחים), ולסנן בנפרד לפי שלב ולפי סוג שירות (בחירת "הכול" מבטלת את הסינון). החיפוש והסינון פועלים יחד. לחיצה על הכותרת "שווי משוער" או "תאריך פנייה" ממיינת את הטבלה לפי העמודה הזו, ולחיצה חוזרת הופכת את כיוון המיון. ליד בלי שווי משוער מוצג עם "-" בעמודה הזו.

**התחברות למאגר הלידים:**
הלידים נשמרים במאגר חיצוני (Airtable) ולא בקובץ קבוע. בפעם הראשונה שפותחים את הדאשבורד במכשיר מסוים, יש להזין בחלונית "חיבור ל-Airtable" שבראש הדף שלושה פרטים: קוד הגישה (Personal Access Token), מזהה המאגר (Base ID), ושם או מזהה הטבלה (Table) - שדה הטבלה ממולא מראש ב-"Leads" ואפשר להשאיר אותו כך אלא אם הטבלה נקראת אחרת. את הפרטים מקבלים מהגורם שמקים את המערכת. לאחר מילוי השדות לוחצים "התחברות". הפרטים נשמרים רק בדפדפן הזה, במכשיר הזה - לא בקוד ולא בשום מקום אחר. כפתור "התנתקות" מוחק את כל הפרטים מהמכשיר (כולל שם הטבלה, שחוזר לברירת המחדל "Leads") וחוזר למסך הריק. כפתור "רענון" מביא מחדש את כל הלידים העדכניים מהמאגר (הדאשבורד לא מתעדכן אוטומטית ברקע, כדי לא לחרוג מהמכסה החינמית של Airtable).

**הוספת ליד:**
לחיצה על "הוספת ליד" פותחת חלונית למילוי פרטי הליד (שם, טלפון, סוג שירות וסוג נכס הם שדות חובה). מספר טלפון מתוקן אוטומטית לתבנית ישראלית רגילה (לדוגמה 050-123-4567); מספר לא תקין מציג הודעת שגיאה. אחרי השמירה הליד נכתב מיד למאגר Airtable ומופיע בטבלה, במדדים ובגרפים.

**עריכה ומחיקה של ליד:**
בעמודת "פעולות" שבטבלה, כל ליד מציג שני כפתורים - "עריכה" ו"מחיקה", וכל שינוי נשמר ישירות במאגר Airtable. עריכה פותחת את אותה חלונית מלאה מראש בפרטי הליד, עם אפשרות לשנות גם את השלב. מחיקה מבקשת אישור לפני שהליד נמחק לצמיתות - גם מהדאשבורד וגם מהמאגר.
